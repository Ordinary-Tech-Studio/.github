Ordinary Tech Studio is a frontier deep-tech research studio pioneering the convergence of **flexible organic thermoelectric semiconductors**, **spatial augmented reality (AR) digital twins**, and **autonomous neural reasoning agents** powered by **Anthropic Claude 3.5 Sonnet**.

### 🔬 Core Research Domains

```
[ Organic Thermoelectric Sensor ]  ──( Micro-ΔT Telemetry )──>  [ Claude 3.5 Sonnet Agent ]
  PEDOT:PSS / SWCNT Hybrid                                      Physics-Informed Reasoning
                                                                            │
                                                                            ▼
                                                         [ WebXR Spatial Digital Twin ]
                                                           Holographic 3D Thermal Mesh
```

1. **Organic Thermoelectric Semiconductors (유기 열전 반도체)**
   - Flexible conducting polymer matrices (PEDOT:PSS, PBTTT) and single-walled carbon nanotube (SWCNT) hybrid nanocomposites.
   - Energy harvesting from ambient thermal differentials ($\Delta T = 5 \sim 25\,\text{K}$) with high Seebeck coefficients ($S > 180\,\mu\text{V/K}$) and suppressed thermal conductivity ($\kappa < 0.3\,\text{W/m}\cdot\text{K}$).
   - Zero-battery self-powered sensor telemetry for wearable computing and embedded IoT.

2. **Augmented Reality Spatial Digital Twins (증강현실 3D 디지털 트윈)**
   - Real-time 3D spatial coordinate projection onto physical hardware via WebXR / OpenXR spatial anchors.
   - Sub-millimeter thermal dissipation visualization through holographic visors (Apple Vision Pro, Meta Quest 3).

3. **Claude-Orchestrated Physics Agents (자율 물리 추론 에이전트)**
   - Deployed on **Anthropic Claude 3.5 Sonnet** as the core autonomous reasoning engine.
   - Continuous closed-loop ingestion of sensor telemetry, validation of Mott formula transport kinetics, and real-time tool calling (`sync_spatial_anchor`) with sub-5ms latency.
